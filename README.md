# Token Extractor Extension

Chrome расширение для извлечения токенов авторизации с различных бирж.

## Поддерживаемые биржи

- **MEXC** - токен из куки `u_id`
- **KCEX** - токен из куки `Authorization`
- **OurBit** - токен из куки `u_id`

## Технологии

- React 18.3.1
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui компоненты

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Добавьте иконки расширения:
   - Создайте иконки размером 16x16, 48x48 и 128x128 пикселей
   - Сохраните их в папку `icons/` с именами:
     - `icon16.png`
     - `icon48.png`
     - `icon128.png`
   - Если иконки отсутствуют, расширение всё равно будет работать, но без визуальной иконки

3. Соберите расширение:
```bash
npm run build
```

4. (Опционально) Создайте zip архив для публикации в Chrome Web Store:
```bash
npm run package
```

Или соберите и упакуйте одной командой:
```bash
npm run build:package
```

Архив будет создан в корне проекта как `token-extractor-extension.zip`.

5. Загрузите расширение в Chrome:
   - Для разработки: Откройте `chrome://extensions/`, включите "Режим разработчика" и выберите папку `dist`
   - Для публикации: Используйте созданный `token-extractor-extension.zip` в Chrome Web Store Developer Dashboard

## Разработка

Для разработки с автоматической пересборкой:
```bash
npm run dev
```

После изменений нужно пересобрать расширение командой `npm run build`.

Для создания архива для публикации используйте `npm run build:package`.

## Использование

1. Откройте любую поддерживаемую биржу в браузере
2. Убедитесь, что вы авторизованы
3. Нажмите на иконку расширения
4. В popup будет отображен токен авторизации
5. Нажмите на иконку копирования, чтобы скопировать токен

## Примечания

- Расширение требует разрешения на доступ к кукам и вкладкам
- Токены извлекаются только с поддерживаемых бирж
- Для других сайтов будет показано сообщение "Не поддерживается"
